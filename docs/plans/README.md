# Build plans

The files in this directory are dated build plans and decision
logs for past work (live transcription, the stop-freeze fix, the
Nov 21 feature round, tinyfix, scheduled recording). They record
what was decided and built at the time — they are **not** current
instructions. For how the app works today, start with the repo
[README](../../README.md) and the docs in the parent directory.
Where a plan has been superseded, a banner at the top of the file
says so.
