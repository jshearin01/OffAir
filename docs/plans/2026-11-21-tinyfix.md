# Plan — tinyfix stage in transcription cleanup (1.0.5)

> Superseded Nov 22, 2026: tinyfix shipped opt-in (off by default),
> not default-on. See
> [docs/notes/cleanup-repeat-rule-2026-11-22.md](../notes/cleanup-repeat-rule-2026-11-22.md).
> The rest of this plan is a dated record of the 1.0.5 build.

## Goal

Add paperweight/tinyfix (MIT, 2.1 MB ONNX) as a default-on stage of
transcription cleanup, running after the deterministic rules and the
names dictionary. Verbatim transcript never modified; output lands in
the derived `transcript-clean` artifact only.

## Evidence (read before writing code)

- Engine source cloned from github.com/cfahlgren1/tinyfix (MIT):
  `src/index.ts`, `src/engine/{fixer,model,rules,trie,typoCost,
  wrongWord}.ts`. Port from source, never from the model card.
- Model files downloaded at pinned revision
  `8efdf5cd91b32584f4077aa0e8ecaf48f7651bef` (see hashes in
  `app/transcription/tinyfix.py`); ONNX I/O verified with
  onnxruntime 1.31.1: inputs left[batch,16] / right[batch,4] /
  candidates[batch,9] int64, output scores[batch,9] float.
- Modes: package "balanced" = EAGER settings {threshold 3,
  costWeight 1.5}; "careful" = CAREFUL {threshold 5, costWeight 0.5}.
  Default mode picked from measurement (below), not assumed.
- Transcription forces `language="en"`; transcript.json carries a
  top-level `language` key. Guard: skip when known non-English,
  run when absent/English.

## Design decisions

1. **Two modules.** `app/transcription/tinyfix_engine.py`: faithful,
   I/O-free port (rules, trie, typoCost, Fixer, WrongWordChecker)
   taking an injected model callable — tests use a fake scorer, so
   rule behaviour is proven without the model. `app/transcription/
   tinyfix.py`: download/cache/verify, onnxruntime session wrapper,
   `TinyfixChecker` orchestration (the `check()` loop from index.ts),
   ignore-list building, segment application.
2. **Both fix kinds by default** (package default), spelling +
   context. Measure each kind separately; restrict the default only
   if measurement shows harm.
3. **Cross-segment context.** Join cleaned segment texts with one
   space, run one `check()` over the joined text (progressive
   `fixedSoFar` semantics preserved), map fixes back by global
   offset with per-segment drift tracking. Segment boundaries do
   not reset the 16-before/4-after window.
4. **Names win.** Every word of every names-dictionary correction
   key/value and every dictionary name goes on the ignore list
   (TS `ignore()` = skip word + learn it). Dictionary runs first,
   as today; tinyfix never re-fixes a dictionary word.
5. **Config default ON.** `AppConfig.tinyfix_enabled=True`,
   `tinyfix_mode="balanced"` (or the measured winner). Settings
   toggle + mode combo in the Settings view advanced group,
   wired through `_sync_advanced_settings_controls` /
   `_advanced_settings_values` / `_on_settings_save` (same pattern
   as pre-roll/enterprise). `clean_session(...,
   tinyfix_enabled=None)` resolves None to the module default True;
   existing tests that call `clean_session` pass False explicitly
   so rule tests stay hermetic (no downloads).
6. **Degradation, never failure.** Missing onnxruntime, missing
   files + failed download, or hash mismatch → `TinyfixUnavailable`
   caught inside `clean_session`: deterministic-only output,
   `tinyfix_skipped` recorded in stats + the clean JSON `cleaning`
   block, plain log line. First-use download shows status via the
   existing cleanup label path; no silent hang.
7. **Cache.** `~/.offair/models/tinyfix/<revision>/`, sha256-pinned
   per file, certifi CA bundle for the download (sherpa pattern).
   Re-download on hash mismatch only.
8. **Stats.** `CleanStats` gains `tinyfix_corrections_applied` and
   `tinyfix_skipped` (reason or ""). Cleanup label appends the
   tinyfix count when > 0.

## Measurement (before calling it done)

- Fixture transcript (meeting-3speakers, 9 turns): run both modes,
  report fixes made, false changes (hand-checked), wall time.
- Synthetic planted-error text (their/there, form/from, to/too,
  your/you're, its/it's, plus correct-text control): correction
  rate per kind, wrong-change rate on the control.
- Pick the default mode from the numbers; record numbers + choice
  in `docs/notes/tinyfix-2026-11-21.md`. Real-meeting accuracy
  stays an open gate — never claimed.
