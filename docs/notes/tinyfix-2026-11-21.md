# tinyfix measurement — Nov 21, 2026

tinyfix (paperweight/tinyfix, MIT) as a stage of transcription
cleanup, after the deterministic rules and the names dictionary.
This note records what was measured, on what evidence, and why
the shipped default mode is **careful**.

## Evidence and its limits

Two evidence sets, both run Nov 22, 2026 on this VM with the real
ONNX model (onnxruntime 1.31.1, CPU):

1. **Fixture script text** — `tests/fixtures/meeting-script.txt`,
   the 9-turn script the TTS fixture audio reads. Run as clean
   text: the right result is *no changes at all*. This measures
   the false-change rate on real meeting-domain text. It is NOT
   a Whisper transcript — the fixture audio was not re-transcribed
   here (it lives outside the isolated copy), so real-meeting
   accuracy stays an open gate.
2. **Planted-error battery** — 15 sentences with Whisper-style
   errors (their/there, form/from, to/too, your/you're, its/it's,
   then/than, affect/effect, spelling slips), plus 10 correct-text
   controls including names, plurals, and product terms. Harness:
   `tests/manual_tinyfix_measure.py`. Verdicts hand-checked.

## Results

| measure | balanced | careful |
|---|---|---|
| Fixture script lines changed (want 0/9) | **1/9** | **0/9** |
| Planted battery exact fixes (want 15/15) | 7/15 | 5/15 |
| Planted battery sentences changed | 14/15 | 14/15 |
| Correct controls wrongly changed (want 0/10) | 0/10 | 0/10 |
| Speed | ~0.11 s/sentence | ~0.11 s/sentence |

False change on the fixture script, balanced only:

- `nine o clock` -> `nine o click` ("click" outscores "clock"
  after "o" — a model preference, not a port bug).

Wrong-direction changes, **both modes** (spelling fixer picking
the more frequent neighbour):

- `wich` -> `with` (wanted `which`)
- `grate` -> `grade` (wanted `great`)

Shared misses, both modes (model margins, not vocab gaps —
`it's`, `effect`, `lose` are all listed mix-ups):

- `its` -> `it's` never fires (`Its to late`, `Its neccessary`,
  `its already`, `its grate` stay as typed).
- `affect` -> `effect` never fires (`then` -> `than` does fire).
- `past` -> `passed` never fires (3 edits out, beyond the
  1-edit neighbour window — an expected engine limit).
- `everyones` -> `everyone` (the possessive form is not a
  candidate the word list offers).

Balanced-only wins (both fire in balanced, neither in careful):

- Sentence-start `Their` -> `They're` in isolation (fires in
  careful too, with fuller left context — see the
  `clean_session` test).
- `loose` -> `lose`.

## Default-mode decision: careful

> Mode default only — since Nov 22, 2026 the stage itself is off
> by default (opt-in); see the amendment below. What follows
> decided the *mode* used when the stage runs.

A default-on cleanup stage must do no harm to correct text
first: a missed fix leaves a visible Whisper error, while a
false change introduces a new error the tool owns. Careful made
zero false changes on the only clean meeting-domain text
measured, where balanced made one, while keeping the core
mix-up fixes (their/there, form/from, to/too, your/you're,
seperate/receive, weather/whether, contractions). The package
default is balanced; the shipped default here is careful, and
balanced stays one Settings change away for transcripts with
many obvious mix-ups.

## Open gates

- Real-meeting accuracy: nothing here measures tinyfix on a real
  Whisper transcript. Validate on a real meeting before trusting
  the fix rate.
  **CLOSED Nov 22, 2026 — see the amendment below.** The
  measurement ran (two YouTube sessions vs published
  transcripts) and the result flipped the default to OFF.
- First-use download on a real Windows machine (status text +
  degrade path are implemented; the download itself was only
  exercised on this VM).
- The `its` -> `it's` gap: if it matters, it needs either a
  deterministic rule of its own or a model-side change upstream
  — it is not fixable by tuning the threshold (both modes miss
  it).

## Nov 22, 2026 amendment — default flipped to OFF (opt-in)

The real-meeting gate above was measured Nov 22, 2026, on two
saved YouTube sessions scored against published transcripts
(measurement reports are dev-machine artifacts, not committed
to this repo; decision record:
`docs/notes/cleanup-repeat-rule-2026-11-22.md`):

- Test 1 (Matt Cutts TED talk, clean speech, 494 words):
  verbatim WER 1.42%; tinyfix careful changed nothing.
- Test 2 (Lex Fridman / Tom Brands interview, 542 s disfluent
  speech, 1,697 words): verbatim WER 8.72%. Tinyfix careful
  made **2 wrong changes** ("lace"→"place", "hate"→"have",
  both at 0.9998 confidence) and fixed **none** of Whisper's 62
  substitutions — none fell in any tinyfix confusion class.

The "0 false changes" fixture result above does not generalize
to disfluent real speech. A default-on stage must do no harm
first, so the shipped default flipped: **tinyfix is OFF by
default (opt-in) since Nov 22, 2026**. The mode default is
unchanged — careful is still the default mode when the stage
is enabled. Explicit opt-ins are preserved across upgrades via
the `tinyfix_enabled_explicit` flag (mirroring the Nov 20, 2026
`whisper_model_explicit` pattern); a pre-flag settings file
with stored `tinyfix_enabled=True` migrates to OFF because it
cannot be told apart from the old ON default. The measurement
record above is left as written — only the default decision
changed.

## Implementation lessons (for the next port)

- **Splitting fixed text back into segments must use per-segment
  length deltas, not original lengths.** The first `fix_segments`
  sliced the fixed text with original segment lengths, silently
  eating a character off every segment after a length-changing
  fix (`Their` -> `They're` turned `books` into `book` in the
  next segment). The fix records each correction's span in
  original coordinates and moves each segment's slice end by
  the net length change inside that segment. Regression test:
  `test_fix_segments_lengthening_fix_keeps_later_segments_whole`.
- **Port word-list tables verbatim, including how the set is
  built.** The TS source builds the newer-words and British-words
  sets with `flatMap(word => [word, word + "s"])` — singular AND
  plural. A hand-transcribed list dropped three lines of
  newer-words and all plurals. The review caught it by diffing
  against the cloned source, not from behaviour.
- **Read the orchestration loop, not just the engine files.**
  `index.ts`'s `check()` adds three behaviours the engine files
  don't show: the after-context stops at the line end, no-op
  replacements are skipped, and code ranges are skipped on
  overlap rather than containment. All three are now in the
  port.
