# Phase 1 (Linux) — Linux capture backend (OPTIONAL). sounddevice /
# PortAudio is only needed to record on Linux; the app runs without
# it (capture reports "unavailable" with install guidance) and it is
# never imported at module load — see app/platform_info.py. The
# sys_platform marker below mirrors pyaudiowpatch above: it installs
# on Linux only, never on Windows. On Linux it ALSO needs the system
# PortAudio library, which pip cannot provide:
#   Debian/Ubuntu: sudo apt install libportaudio2
#   Fedora:        sudo dnf install portaudio
# Without that library, `import sounddevice` fails with
# "PortAudio library not found" and OffAir falls back to the
# no-capture state with the same guidance.

# Phase 2 — transcription (CPU-only). faster-whisper pulls in ctranslate2;
# it does NOT pull torch/CUDA.

# PyAV pin: faster-whisper 1.2.1 declares only `av>=11`, but its
# decode_audio() calls av.open(..., metadata_errors="ignore"), a kwarg
# PyAV removed in v15 — with av>=15 every transcribe() call fails with

# Phase 3 — full diarization (CPU-only). pyannote.audio pulls in torch

# "You vs Remote" mode needs no pyannote, no torch, and no token.
# No CUDA packages are listed anywhere in this file — torch installs
# as the CPU-only wheel by default from PyPI.
